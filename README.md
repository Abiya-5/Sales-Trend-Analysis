#  Sales Trend Analysis Using SQL

##  Project Overview

This project analyzes e-commerce sales data to identify monthly sales trends, revenue patterns, and order volume using SQL aggregation functions.

The analysis was performed using **DB Browser for SQLite**. 
The dataset was imported from a CSV file and SQL queries were used to calculate monthly revenue and order volume.

##  Objective

The main objective of this project is to:

* Analyze monthly revenue trends.
* Calculate monthly order volume.
* Group sales data by year and month.
* Identify the top-performing months based on sales.
* Analyze yearly revenue trends.
* Practice SQL aggregate functions such as SUM() and COUNT().


##  Tools Used

* DB Browser for SQLite
* SQLite
* CSV Dataset
* GitHub

##  Dataset

The dataset used for this project is:

ecommerce_dtaset.csv


##  Key Insights

* Monthly sales trends can be identified by grouping records based on year and month.
* SUM("Sales")helps calculate total revenue.
* COUNT(DISTINCT "Order ID")helps calculate the number of unique orders.
* GROUP BY is used to aggregate data based on specific categories.
* ORDER BY helps organize results chronologically or based on revenue.
* The LIMIT clause can be used to identify the top-performing months.
